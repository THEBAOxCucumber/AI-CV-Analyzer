# เช็กลิสต์วันสาธิต

## ก่อนวันสาธิต (ครั้งเดียว)

1. ตั้ง Embedding เป็น Ollama ให้ทำงานได้โดยไม่ต้องใช้อินเทอร์เน็ต (ดู README หัวข้อ *Offline embeddings*)
2. ดาวน์โหลดโมเดล

   ```powershell
   ollama pull qwen3:4b-instruct
   ollama pull qwen3-embedding:0.6b
   ```

3. GPU 4 GB: ตั้ง `OLLAMA_NUM_GPU=99` ใน `backend/.env` (วิเคราะห์ ~20 วินาที แทน ~2 นาที)

## วันสาธิต (ก่อนเริ่ม ~10 นาที)

1. เปิด Docker Desktop และ Ollama
2. เปิดบริการ

   ```powershell
   cd backend
   docker compose up -d
   npm run dev
   ```

   อีกหน้าต่างหนึ่ง (โฟลเดอร์หลัก):

   ```powershell
   npm run dev
   ```

3. สร้างบัญชีสาธิตใหม่ (ลบของเดิมแล้วสร้างใหม่ ~2–3 นาที เพราะ AI วิเคราะห์จริง 5 ครั้ง)

   ```powershell
   cd backend
   npm run demo:seed
   ```

4. ตรวจความพร้อม + โหลดโมเดลค้างไว้

   ```powershell
   npm run demo:check
   ```

   ต้องขึ้น `✓ พร้อมสาธิต` และ "โมเดลวิเคราะห์อยู่บน GPU ทั้งหมด"

5. ปิดโปรแกรมที่ใช้ GPU หนัก (เกม, ตัดต่อวิดีโอ) — ถ้า VRAM ไม่พอ ระบบยังทำงานได้แต่ช้าลงมาก

## ลำดับสาธิตที่แนะนำ

1. **หน้าเข้าสู่ระบบ** — ชี้ข้อความรายวิชาและลิงก์นโยบายความเป็นส่วนตัว
2. **Dashboard** — สถิติ, การวิเคราะห์ล่าสุด, ทักษะที่ตรงกับงาน
3. **ผล Job Match สมชาย × Backend** — วงคะแนน, สัดส่วนทักษะ, คำแนะนำ, ปุ่มคัดลอก
4. **เทียบกับ สมชาย × Frontend** — คะแนนต่ำ เห็นทักษะที่ขาดชัด
5. **อัปโหลด Resume สด** — ใช้ `backend/demo/demo-resume-frontend.pdf` แล้วกดวิเคราะห์ (~20–30 วินาที)
6. **หางาน** — ค้นหา "Frontend Developer" (ต้องใช้อินเทอร์เน็ต Careerjet ใช้ 5–14 วินาที)
7. **ข้อมูลเชิงลึก / ประวัติ**
8. **ตั้งค่า** — ธีมมืด, ดาวน์โหลดข้อมูล, ลบบัญชี (อย่ากดลบจริงกับบัญชีสาธิต)
9. **มือถือ** — ย่อหน้าต่าง/DevTools ให้เห็นเมนู ☰
10. **หน้า Admin** — `http://localhost:5000/admin/` (ต้องใช้บัญชี ADMIN จริง)

## ถ้ามีปัญหา

| อาการ | วิธีแก้ |
|---|---|
| `demo:check` ขึ้น ✗ ที่ MySQL / Redis / Qdrant | `docker compose up -d` ในโฟลเดอร์ `backend` |
| วิเคราะห์ค้างนาน / ช้ามาก | `npm run demo:check` ดูว่าโมเดลอยู่บน GPU ไหม, ปิดโปรแกรมที่ใช้ GPU |
| อัปโหลดแล้วสร้าง vector ไม่ได้ | ตรวจ Ollama เปิดอยู่ และมีโมเดล `qwen3-embedding:0.6b` |
| หางานไม่ขึ้น | ต้องใช้อินเทอร์เน็ต — ข้ามไปโชว์ผล Job Match ที่สร้างไว้แล้ว |
| เข้าสู่ระบบไม่ได้ "มีคำขอมากเกินไป" | รอ 15 นาที หรือรีสตาร์ต Redis (`docker compose restart redis`) |
